## Multiplexer : (MUX)
>> many to one 
>> 2^n data inputs and n outputs
>> acts as data selector
>> in real life , in sector of cable tv connections mux is used.
## Demultiplexer: (DEMUX)
>> one to many 
>> n data inputs and 2^n outputs
>> acts as data distributor
I practice truth table and implementation circuit for both mux and demux for 4:1 and 1:4 mux and demux , 8:1 and 1:8 mux and demux .
## Encoder :
>> 2^n input lines and n binary output
>>encoder also converts normal data into binary data input lines to output
>> in communications it used in transmitter side
>> only one input line is active at a time .
>> eg: keyboard calculators ..
>> practice 4:2 encoder , truthtable and implementation diagram.
## Priority encoder :
>> for overlapping inputs or two or more inputs at a same time causing confusion to encoder for output conversion .. to overcome this priority encoder introduced . In this if many inputs means it checks for highest msb which will be the precedence .
## Decoder :
>> n inputs to 2^n outputs
>> only one output line is activated
>> used in receiver
>> eg: 7 segmented display
