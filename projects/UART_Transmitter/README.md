# UART Transmitter (Verilog HDL)

## Overview
This project implements a parameterized UART Transmitter in Verilog HDL.

## Features
- Parameterized baud rate generator
- FSM-based UART transmitter
- 8-bit serial transmission
- Vivado behavioral simulation
- Custom Verilog testbench

## Project Structure
- rtl/
- tb/
- screenshots/

## Tools Used
- Verilog HDL
- Vivado
- XSim
